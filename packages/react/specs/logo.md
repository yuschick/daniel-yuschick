# Logo

## Purpose

The Daniel Yuschick brand mark, for branded regions such as the page header and footer. It renders a `<span>` holding an inline SVG of the initials, followed in the `full` lockup by the name as real HTML text. It's static and non-interactive.

## Anatomy

A root `<span>` laid out as `inline-flex` with `align-items: center`, matching Figma's horizontal, vertically centered layout. It's the same element in both lockups (D1). It sets `vertical-align: middle`, so in inline context, such as inside a link, it centers on the surrounding text (D11). Its block size is never set: it hugs its tallest child, the SVG.

- **Mark:** one inline `<svg>` with `viewBox="0 0 119 194"` and paths filled with `currentColor` (D1, D10). Its `block-size` is the size's component token, from Figma's root height (mark lockup) and `Logo Initials` height rows, and its `inline-size` is `auto`, so the width follows the viewBox ratio (D3). It never shrinks (`flex-shrink: 0`). The four `Vector` layers are path data inside the SVG, not CSS boxes.
- **Name (`full` only):** a `<span>` after the SVG, containing the text `Daniel Yuschick` in title case. It is uppercased only by `text-transform: uppercase` (D5), and set with `white-space: nowrap`, so it never wraps (D9). Figma's `fontStyle` maps to CSS `font-weight`. `letter-spacing` stays unset, because Figma's value is 0. The font face is loaded by `@dy/fonts`, not by Logo.
- **Gap:** in the `full` lockup the root's `gap` is Figma's `itemSpacing`. The `mark` lockup has a single child, so it sets no gap.
- **Color:** the root sets `color` to `--dy-color-text-strong`, so the name inherits it and the SVG paths follow through `currentColor`.

There are no other elements, and no padding or margin: the reset zeroes both, and Figma's padding is 0.

## API

| Prop   | Type                               | Values     | Default | Figma  | Source       |
| :----- | :--------------------------------- | :--------- | :------ | :----- | :----------- |
| lockup | `Lockup`                           | mark, full | mark    | lockup | figma, D6    |
| size   | `Extract<Size, 's' \| 'm' \| 'l'>` | s, m, l    | m       | size   | figma, D2    |
| ref    | `React.Ref<HTMLSpanElement>`       | -          | -       | -      | TS-01, RX-01 |

`LogoProps` extends `SanitizedHTMLAttributes<React.HTMLAttributes<HTMLSpanElement>>` with `role`, `aria-label`, `aria-labelledby`, `aria-hidden`, `tabIndex` and `children` omitted (D8).

In the props table (FS-07), `lockup`'s Type is `Lockup` with `LOCKUPS` as its options, and `size`'s Type is `Size` with a stories-local `LOGO_SIZES` array of `s`, `m` and `l` as its options, as Button does.

WAI-ARIA pattern: none. Logo is not a widget, so no APG pattern applies. The mark lockup exposes the ARIA `img` role, and the full lockup exposes plain text.
