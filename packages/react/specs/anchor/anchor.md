# Anchor

## Purpose

Every control that navigates and carries a text label. It renders a native `<a href>` in one of two forms: the default, styled like Button, or `variant="inline"`, recolored text inside a run of prose. `intent` communicates meaning and `emphasis` communicates priority within a screen region.

## Anatomy

An `<a>` containing one internal `<span>` that wraps `children` and, only when D12 applies, a visually hidden `<span>` holding the appended text, inside that label `<span>`. The text begins with a space, held inside the hidden `<span>` so nothing visible is added (D19). Both forms render this same structure (D15), so `Anchor.tsx` has one template path.

The default form is `inline-flex`, centered on both axes as Figma's layout shows, including when a tall label makes it grow. Labels wrap, centered. `max-inline-size: 100%` caps it and `overflow-wrap: anywhere` on the label breaks long unbroken words. `text-decoration: none` removes the native underline (D7). Figma's `fontStyle` maps to CSS `font-weight`, and `letterSpacing` stays unset because Figma's value is 0. The focus ring is the anchor's own `outline`, offset from the border edge; Figma's Focus ring radius row is met by the outline following the anchor's `border-radius` (D8).

The inline form is `display: inline`, so it wraps across lines with the sentence. It sets no typography: every font property inherits from the surrounding text, and the Figma tokens table's `fontFamily`, `fontStyle`, `fontSize` rows, which Figma needs only to draw it, apply to the default form alone (D3). It has no fill, radius, minimum height, inline padding or border (D3, D14). Its only spacing is the invisible block padding from D10, which doesn't change line height or surrounding text. The internal label `<span>` is unstyled there.
