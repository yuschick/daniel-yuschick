# Button

## Purpose

Every action that carries a text label. It renders a native `<button>` and nothing else. `intent` communicates meaning and `emphasis` communicates priority within a screen region.

## Anatomy

A `<button>` containing one internal `<span>` that wraps `children`, so a label with inline markup stays a single flex item and wraps as a sentence. There are no other elements. The button is `inline-flex`, centered on both axes as Figma's layout shows, including when a tall label makes it grow. Labels wrap, centered. `max-inline-size: 100%` caps the button and `overflow-wrap: anywhere` on the label breaks long unbroken words, so nothing overflows. `box-sizing: border-box` comes from the consumer's reset, not from Button (D29). The focus ring is the button's own `outline`, offset from the border edge (D30). Figma's Focus ring radius row is met by the outline following the button's `border-radius`, not set separately (D33), which follows its `border-radius`, not an extra element. Figma's `fontStyle` maps to CSS `font-weight`. `letterSpacing` stays unset, because Figma's value is 0.
